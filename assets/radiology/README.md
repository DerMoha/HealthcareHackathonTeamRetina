It is a normal wrist, used as an illustrative stand-in for a radiograph with "no definite fracture visible". The viewer says so under the report.

MRI and CT have **no image**. The freely licensed scaphoid MRI/CT images found on Wikimedia Commons show different conditions (non-union, perilunate dislocation) and would misrepresent the case, so the viewer shows a labelled simulated report instead.
